# Hamming extensions and a short proof from Mináč et al.'s cycle answering Nguyen and Tân's primeness question

**Authors:** Haobo Ma, Wenlin Zhang

Using the cycle example of Mináč, Muller, Nguyen and Tân (2022, Corollary 2.5), we give a short negative answer to Nguyen and Tân's Question 4.17 (arXiv:2508.10348v1, Section 4.3, p. 19): Γ(Z/8Z,{1,−1}) = C₈ is prime, connected and anti-connected, with adjacency nullity two. More generally, C_n has these graph properties for n ≥ 5 and is singular exactly when 4 divides n. Extending Chen's binary polynomial construction with the tensor spectrum described by Sander, we realize every Hamming graph H(d,q) over a prime-power alphabet as a subgroup-unit Cayley graph of a Frobenius group algebra. For d ≥ 2, except (d,q)=(2,2), it is prime and anti-connected; it is singular exactly when q divides d, with nullity binomial(d,d(q−1)/q)(q−1)^(d(q−1)/q). These examples also answer Question 2.20 of arXiv:2603.21239v1 negatively. Finally, a short proof of Hendrickson's duality answers the supercharacter-axiom question in Remark 2.2 of the first source affirmatively.
